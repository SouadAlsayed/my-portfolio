# Souad Alsayed | Portfolio
 
A personal portfolio website showcasing my front-end projects, skills, and background. Built with Next.js, TypeScript, and Tailwind CSS.
 
**Live site:** [https://souadalsayed-dev.vercel.app/](https://souadalsayed-dev.vercel.app/)
 

<img width="1897" height="868" alt="image" src="https://github.com/user-attachments/assets/2ec98615-01af-42de-86ec-4461cc440e5e" />


 
## Features
 
- **Home page** with hero, featured projects, skills, about, and contact sections
- **Projects page** (`/all-projects`) listing every project
- **About page** (`/about-me`) with my full background
- **Smooth scrolling** navigation that works across all pages
- **Responsive design** for mobile, tablet, and desktop
- **Data-driven content**: projects, skills, and social links live in one data file

## Tech Stack
 
- [Next.js](https://nextjs.org/) (App Router)
- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Hugeicons](https://hugeicons.com/) for icons
